# 📊 Excel Sales Analytics

## 📌 Overview
This project analyzes company sales performance using Microsoft Excel.  
It provides insights into **revenue trends, profitability, customer performance, and market growth**.  
The analysis is supported with dashboards and well-structured PDF reports.

---

## 📂 Files in this Project
- **Customer Performance Report.pdf** → Analyzes sales by customer segment
- **Gross Margin % by Market (Sub Zone).pdf** → Profitability analysis across regions
- **Market Performance vs Target Report.pdf** → Tracks actual vs target performance
- **P & L By Fiscal Year.pdf** → Yearly profit and loss statement
- **P & L By Market.pdf** → Profit and loss segmented by market
- **P & L Statement By Month.pdf** → Monthly P&L trends

---

## 🛠 Tools & Skills
- **Excel**: Pivot Tables, Charts, Power Query
- **KPIs**: Revenue, Profitability, Gross Margin, Target Achievement
- **Reports**: Dynamic dashboards and management-ready insights

---

## 📈 Key Insights
- Identified **top-performing and underperforming markets**
- Evaluated **customer-level profitability**
- Monitored **monthly and yearly P&L trends**
- Compared **actual performance vs sales targets**
